# Japan Trip 2027

A phone-first trip companion for a family trip to Japan, 13 to 24 April 2027: daily route, booking checklist, gluten-free guide, a celiac card in Japanese, and emergency numbers. Hebrew, right-to-left.

Open `index.html` in a browser, or use the GitHub Pages site. Checkmarks and notes are saved on each device only. After the first visit with internet, the Pages site also opens offline.
